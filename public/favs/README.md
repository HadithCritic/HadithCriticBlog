# HadithCritic Favicons

Copy every file in this folder into your Astro project's `public/` directory.

Then add these tags inside `<head>` in your BaseLayout:

```html
<link rel="icon" type="image/svg+xml" href="/favicon.svg" />
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png" />
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png" />
<link rel="shortcut icon" href="/favicon.ico" />
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png" />
<link rel="manifest" href="/site.webmanifest" />
<meta name="theme-color" content="#0F0F10" />
<meta name="msapplication-TileColor" content="#0F0F10" />
<meta name="msapplication-config" content="/browserconfig.xml" />
```

Generated from the HadithCritic three-hexagon logo in black and antique gold.
