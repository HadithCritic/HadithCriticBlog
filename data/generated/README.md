# Generated build inputs

Written by `npm run build:narrators` from `ifta.db` and the Shamela criticism
parquet, neither of which is in this repository. These files are committed
because a CI runner has no access to those sources.

Nothing here is served by the site. These files are retained as generated
research data, but the current static corpus deployment does not consume them.

`criticism/` holds the jarh and ta'dil statements for every narrator.

`narrators/` holds the full dossier records, previously used by database-backed
narrator pages. The current site no longer has those database-backed routes.

`criticism/` holds generated jarh and ta'dil statements. Keep these files until
their upstream source and any future use are confirmed before deleting them.
