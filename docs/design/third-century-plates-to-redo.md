# Third-century plates to redo

117 of the 991 chapter plates came back as the same stock garden (a pergola, palms, orange blossom and roses around a fountain) instead of the scene their prompt describes. They work on the page, but side by side in the index they read as one picture repeated. Two more are collages of several scenes. This list is those plates, found by comparing every plate against three of the clearest repeats and keeping the ones that match at 0.86 or more.

Each plate keeps its prompt in `docs/design/third-century-image-prompts.md` under the chapter number below. Save the new image over the old file at the same path (`public/images/hadith/chapter-covers/<slug>/NN.webp`, 880 x 1056). Nothing in the code needs to change.

## Add this to the prompt when regenerating

```text
Show only the objects and place described, filling the frame. No garden frame: no pergola, no trellis, no climbing roses, no orange or blossom branches along the edges, no fountain unless the scene names one.
```

For a negative prompt, add: `pergola, trellis, rose bush, blossom branches, fountain, garden frame, collage, split panels`.
